# v1.0.0 — Published-results visualization and reproducibility scaffold

Initial companion to “Challenges in applying DeepInsight for cyber threat detection” (10.11591/eei.v15i2.9649).

Includes aggregate and per-class result CSVs, a Python plotting script, PNG/PDF/SVG charts, reported experiment settings, source provenance, and a checklist of missing experimental artifacts.

The figures reproduce rounded values reported in the paper. The original model training experiments have not been rerun. Raw datasets, model training code, checkpoints and predictions are not included. The feature-count discrepancy and other missing details are documented.

Release prerequisites: confirm package creators and licenses, prepare package-specific citation and Zenodo metadata, and enable the repository in Zenodo before publishing this release.
